Who I Am

About Me

I'm a Senior DevOps & Cloud Engineer at Trinesis Technologies, managing production infrastructure for US-based clients across AWS, GCP, and Azure.

I specialize in Infrastructure as Code with Terraform (9,000+ lines of production IaC), container orchestration with ECS Fargate, Cloud Run, and AKS, and building robust CI/CD pipelines with Jenkins, GitHub Actions, and CodeDeploy.

I also administer Microsoft 365 for US clients: Exchange Online, Entra ID, Intune and Defender, licensing, SPF/DKIM/DMARC email security and security incident response, scripted in PowerShell. On the network side I design VPC/VNet, VPN, NAT, DNS and TLS across AWS, Azure and GCP.

My recent focus has been on FedRAMP/FIPS compliance for a US government client, implementing security hardening across 30+ microservices with zero compliance violations.

I'm also exploring AI + DevOps — building intelligent automation agents that can audit infrastructure, review Terraform code, and diagnose production issues using natural language.
